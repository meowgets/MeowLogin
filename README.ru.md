# MeowLogIn

Плагин авторизации для Paper-серверов с диалоговым GUI, интеграцией с Telegram-ботом и сбросом пароля через бота.

[English version](README.md)

## Возможности

- Авторизация через диалоговое окно
- Резервный режим через чат (`/login`, `/register`)
- Мультиязычность (en, ru + свои через папку `lang/`)
- Интеграция с Telegram-ботом:
  - Привязка аккаунта через `/link`
  - Сброс пароля через `/resetpassword`
  - Смена пароля из Telegram (`/newpass`)
  - Отвязка (`/unlink` и в игре, и в боте)
- Опциональная обязательная привязка Telegram (`require-telegram-link`)
- Схема: логин → привязка Telegram → игра (когда `require-telegram-link: true`)
- Админ-команды:
  - `/unreg <player>` — удалить игрока из базы (право `meowlogin.unreg`)
  - `/meowlogin reload` — перезагрузить конфиг и языки
  - `/meowlogin lang <code>` — сменить язык
- Настраиваемая блокировка действий для неавторизованных игроков
- Лог событий (`meowlogin.log`): регистрация, вход, неудачный вход, сброс пароля, привязка/отвязка Telegram, анрег админом
- Уникальная привязка Telegram: 1 чат = 1 аккаунт, 1 аккаунт = 1 чат

## Требования

- Paper 26.2 (на других версиях не тестировался)
- Java 25

## Установка

1. Положи `MeowLogIn.jar` в папку `plugins/`.
2. Запусти сервер один раз, чтобы сгенерировались конфиги.
3. Отредактируй `plugins/MeowLogIn/config.yml`.
4. (Опционально) Настрой Telegram в `config.yml`:

   ```yaml
   telegram:
     enabled: true
     token: "ТВОЙ_ТОКЕН_БОТА"
     bot-username: "ТвойБот"
   ```

5. Перезапусти сервер.

> **Важно:** после указания `telegram.token` и `telegram.bot-username` обязателен **полный перезапуск сервера**. Команда `/meowlogin reload` эти параметры не применяет — бот запускается только при старте плагина.

## Команды

| Команда | Описание | Право |
|---------|----------|-------|
| `/login <пароль>` | Войти | — |
| `/register <пароль> <пароль>` | Зарегистрироваться | — |
| `/link` | Привязать Telegram (после входа) | — |
| `/unlink` | Отвязать Telegram (после входа) | — |
| `/resetpassword` | Запросить сброс пароля через Telegram | — |
| `/meowlogin [mode\|lang\|reload]` | Помощь / персональная смена режима авторизации или языка / релоад конфига | — |
| `/unreg <игрок>` | Удалить игрока из базы (только для админов) | `meowlogin.unreg` |

## Команды Telegram-бота

| Команда | Описание |
|---------|----------|
| `/start <код>` | Привязать Minecraft-аккаунт по коду из `/link` |
| `/newpass <пароль>` | Сменить пароль |
| `/unlink` | Отвязать Telegram от Minecraft-аккаунта |

## Конфигурация

Основные параметры в `config.yml`:

- `default-language` — код языка по умолчанию
- `spawn-mode` — `DEFAULT` (игрок остаётся на месте выхода) или `FIXED` (телепорт на фиксированную точку до авторизации)
- `auth-timeout` — секунды до кика, `0` — отключено
- `min-password-length` — минимальная длина пароля
- `require-telegram-link` — если `true`, игрок обязан привязать Telegram, чтобы играть (по умолчанию `false`)
- `telegram-hint-every` — как часто показывать подсказку про `/link` (`0` — отключить, `1` — каждый заход, `3` — каждый третий)
- `block.*` — что блокировать неавторизованным игрокам
- `telegram.enabled` / `telegram.token` / `telegram.bot-username` — настройки бота
